# components/crud

Shared building blocks for the admin CRUD pages (plan/23-project-structure.md).
Compose these per entity under `src/features/<domain>/`.

| Component       | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `PageHeader`    | Title + one-line description + right-aligned action slot.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `ActionButton`  | `Button` + leading icon + optionally responsive label (`+ New`, …).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `ConfirmDialog` | Small yes/no modal — deletes, discard-changes prompts.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `FormModal`     | Centered modal wrapping a form; unsaved-changes guard when `dirty`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `useScrollLoad` | Cursor-paginated "load on scroll" — first page on mount, an `IntersectionObserver` sentinel appends the rest (fires immediately if the first page didn't already fill the viewport, so a short list keeps auto-loading before handing off to a real scroll gesture). Optional `resetKeys` reloads from scratch when a status tab / search query / etc. changes (a TanStack-Query-style query key); optional `enabled` skips fetching entirely for a data source that isn't the one currently on screen. Used by Audit Log, the Staff directory, and Categories' flat views (Archived/All + any search — the active tree stays load-all, see that feature's README). |

Generic strings live in the `admin` message namespace (`actions.*`, `form.*`,
`list.*`).
